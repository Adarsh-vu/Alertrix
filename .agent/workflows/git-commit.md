# Git Commit Workflow

1. After making any changes, stage the files with `git add`
2. **ALWAYS ask the user for their preferred commit message** before committing
3. Create a **new commit** (never amend previous commits unless explicitly asked)
4. Push to origin with `git push`

This ensures a clean, professional commit history at the end of the project.
